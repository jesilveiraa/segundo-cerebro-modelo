# Clientes

Um contexto por cliente real. Ainda não há clientes cadastrados.

Quando houver material, criar `<nome-do-cliente>/README.md` e acrescentar seu link neste índice. Usar nome legível e consistente. Não criar pastas vazias, clientes fictícios ou reuniões retroativas.

A entrada do cliente reúne contexto, fontes, prioridades confirmadas e documentos relevantes, com data e origem. Informações específicas ficam aqui; critérios reutilizáveis e revisados ficam em processos/.

Registros adicionais de reunião ou entrega ficam junto do cliente quando existirem. Preservar fontes e distinguir o que foi preparado do que ocorreu. O acesso desta base é interno da empresa; materiais para seus clientes exigem compartilhamento próprio.
