# Processos

Como a empresa trabalha: procedimentos, critérios e formas de conferir uma entrega. Ainda não há processos documentados.

Criar um arquivo por assunto, como `preparar-reuniao.md`, quando houver conteúdo. Acrescentar o link nesta entrada. Cada documento informa objetivo, fonte, data, estágio de validação e os passos ou critérios necessários para aplicá-lo.

Um rascunho ou uma hipótese fica identificado no documento. Só registrar como processo validado quando houver revisão e evidência. Resultados de uma aplicação específica ficam no cliente correspondente; a regra comum fica aqui.

As skills consultam esses documentos, sem copiar seu conteúdo para manter outra versão.
