## Documentação dos processos

Este mapa não exige detalhar agora cada processo. Quando houver conteúdo específico, criar um arquivo por assunto, como `preparar-reuniao.md`, e acrescentar o link aqui. Cada documento informa objetivo, fonte, data disponível, estágio de validação e os passos ou critérios necessários para aplicá-lo.

Rascunhos e hipóteses permanecem identificados. Um processo só é validado após revisão e evidência. Resultados de uma aplicação específica ficam no cliente; a orientação comum fica aqui. As skills consultam os documentos sem copiar seu conteúdo.
